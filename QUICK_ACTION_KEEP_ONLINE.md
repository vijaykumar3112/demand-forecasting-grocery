## 🚨 TROUBLESHOOTING

### Issue: UptimeRobot shows "Down"
**Fix:** 
1. Check your API is deployed on Render
2. Go to: https://dashboard.render.com
3. Verify service is running
4. Copy the actual URL and update UptimeRobot

### Issue: Don't know my API URL
**Fix:**
1. Go to: https://dashboard.render.com
2. Click on your API service
3. Copy the URL at the top
4. Should look like: `https://demand-forecasting-api-XXXX.onrender.com`

### Issue: API still goes to sleep
**Fix:**
1. Verify UptimeRobot interval is **5 minutes** (not 15+)
2. Check monitor is **enabled** (green toggle)
3. Wait 30 minutes and test again
